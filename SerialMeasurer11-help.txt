Preface :

I have created this program for serial devices what can communicate 
via USB-RS232 like Arduino etc. coupled with next modules of sensores 
like HW-487 or HW-827 etc, in this case with my test modules
for measuring U in Volts, resistor Rx in Ohms and capacitors Cx 
above all in mikro Farads.

Producted data are in format .txt, .tab or .meas files 
and they are only for your personal information purpose 
and they cannot be taken as generallz results in any case.

I have informed and publiced this help and next files include .exe file

Communication:
= = = = = = = =
Program was created for devices what can communicate with PC OS protocol RS232,
so com ports of PC for communication between personal computers
with connectors RS232 or USB connectors
and devices like microcomputers Arduinos or Espressif 
and their BPM or ECG modules for example.

Simply manual how to use SerialMeasurer11
= = = = = = = = = = = = = = = = = = = = =

Main(home) window
= = = = = = = = =
- after main(home) window is on and OK, push Device Set Button
- or Com Button, if you are not sure if your com port is set well
- Open Port window will be shown

Com window
- - - - - -
- push Open button
- if handle of predefined com port will set on, push Purge button and purge this comm port
- choose Device Par button and Osc Par window will be shown

Device Set window
- - - - - - - - -
- choose Q command from Call combobox and push Call button
- if answer will be OK and green round shape light will be on, you can continue with next parameters
- for example choose G Y Led from Call combobox and push Call button
- yellow led on your device (if is installed) will light on
- choose I command from Serial Commands combobox
- push Read button and wait  for answer in Answer or Result field
- if your asked device is on, the one will be confirmed
- or you will be asked to accept it
- or choose K command from Serial Commands combobox
- choose nr of asked device from device combobox
- push Set button and wait  for answer in Answer or Result field
- when this answer will repeat your slave device number, this one is on-line
- if your choosed device is on, it will be confirmed, else zero will be in answer
- push Read Par button to read pre-set parameters for Measure windows
- when your device is connected and it is on,
- push Data button to read data from your device via command A to be sure your device is measured OK 

Measure window
- - - - - - - -
- choose your task from listbox with tasks
- choose plotter type from plotter combobox A or B (more quick when data reading)
- if you need record of data, cross Record checkbox, New file button will be wisible
- occasionally write note of you to Note field
- press Data file button to set the header of this data file what will be used for next data registration
- press Graph Par button to choose the suitable parameters for time and data axes
- press Graph and  Graph window will be shown
- press Display U, if you will meas DC U in Volts, only
- press Display RC, if you will meas Rx in Ohms or Cx in Farads
- see detail description of Rx and Cx measuring in Display RC window description

Grapf window
- - - - - - -
- set in Radiobutton Time axe for the type of graph time axe shift 
  when this time will be on the end of time range
- see and follow your measuring data, then press Stop button
- after all measuring ends, press Task button
- confirm if you want to save your data or on your hard disc
  or into databox for next analysation in tabs or graphs.
- press Menu button and Menu window will shown

Menu window
- - - - - -
- clik on the column with data
- choose Tab Par or Graph Par
- set parameters for table or graph
- click on the Table or Graph Image buttons

Display RC window
= = = = = = = = = 

Rx measuring
- - - - - - -
- choose Rx measuring in Radio group buttons
- press Meas RC button
- when U ref in range 0 to 1024 is measurred, press Set U ref buttons
- choose expexted range of Rx in R ref combobox
- if you do not use a switcher, change R ref for Rx measuring manually in your contact field
- connect your measured resistor Rx to Rx contacts on your Meas RC module
- wait for measuring of U rx in range 0 to 1024 again from Rx/(Rref + Rx) dividier 
- press Count Rx button and the Rx value will be counted and displayed in Rx edit window
- if you will test of accuracy of Rx measure, use your own R ref insted of Rx resistor 

Cx measuring
- - - - - - 
- choose Cx measuring in Radio group buttons
- press Meas RC button
- when U ref in range 0 to 1024 is measurred, press Set U ref buttons
- if you do not use a switcher, change R ref for Cx measuring manually in your contact field
- choose expexted range of Cx in C in combobox
- connect your measured capacitor Cx to Cx contacts on your Meas RC module
- wait for measuring of U cx in range 0 to 1024 again from Crx/(Rref + Crx) dividier 
- press Meas Tau button and the Cx will be re-charged due R ref 
- time of re-charging  and U cx will be displayed in edit windows
- expected low range of U tau re-charging will be counted and displayed in  edit window
- note U tau is counted from known formula Utau (in %) = Uref x 38.5 %
- 38.5 % for the real measuring is in window  Tau in % corected usually in about 40 %
- after the U tau will be under the counted limit, re-charging will be stoped
- time of Tau constant will be displayed in  edit window
- press Count CX button and the capacitance of Cx will be counted from formula Cx = Tau / R ref
- if you will test of accuracy of Cx measure, use your own C ref insted of Cx capacitor

List of used commands for SerialMeasured program:
= = = = = = = = = = = = = = = = = = = = = = = = =
Command	Answer
- - - - - - - -
A	*A,400,#,CRLF   number is readed analog data example
B	*B,399,342,346,420,#,CRLF	Cr is carriage return, LF is Line Feed
C	*C,399,342,346,420,399,342,346,401,#,CRLF - CRLF are marks from RS232 protocol
D	measuring in cycle - neither used nor realised
E20	*P,20,400,500,100,#,CRLF = returned all parameters	
	   20, data time step in mikroseconds
	      400, off-line readed data with osciloscope here not used
	          500, max - " -
	              100, offset for readed data (usually zero) hjere not used
F	read all transfer detail comments from Arduino (for tests with ESP)
G	set of TTL 0 (zero) of digital output D6
H	set of TTL 1 (zero) of digital output D6
J	*J,analogInput,dataInverted,#,CRLF = info about in devices setted parameters
I	*I,nr,#,CRLF = test of aktual connected slave device nr in ESP-NOW system
P	*P,20,300,500,10,#,CRLF = read parameters
Q	stop of reading details after teste of commands in  ESP-NOW system 
R	*R,20,300,time,10,#,CRLF = time is the previous data measuring time in microseconds
S	*S,20,300,time,10,#,CRLF = stop of reading B,C,D data in cycle here not used
V0	*V,0,#,CRLF - set ou analog input A0 of command A
V1	*V,1,#,CRLF - set ou analog input A1 - '' - etc.
